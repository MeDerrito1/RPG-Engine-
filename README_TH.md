# RPG Engine v0.2.0

ส่วนเสริมภาษาไทยสำหรับ SillyTavern ธีม Gothic ออกแบบสำหรับจอมือถือและเดสก์ท็อป

## ฟีเจอร์

- แผงตั้งค่าแบบ `inline-drawer` ตามรูปแบบมาตรฐานของ SillyTavern
- ปุ่มลอยเปิด Popup ได้จากหน้าแชต และมีปุ่มเปิดจากแผง Extensions
- Popup มีแท็บ ภาพรวม, สถานะ, กระเป๋า, ภารกิจ, ความสัมพันธ์, เรเวน และตั้งค่า
- ข้อมูล RPG ผูกกับ `chatMetadata` ของแต่ละห้องแชต
- NPC Profile: ชื่อ/นามสกุล/ฉายา/อายุ/เผ่าพันธุ์/อาชีพ/สังกัด/สถานะ/สถานที่/รูปลักษณ์/บุคลิก/ภูมิหลัง/บันทึก และประวัติความสัมพันธ์
- รูปโปรไฟล์ NPC และผู้ช่วยเลือกจากคลังภาพ/กล้องผ่าน file picker ของอุปกรณ์ รูปจะถูกย่อและบีบอัดก่อนบันทึก
- ความสัมพันธ์ 5 มิติแยกจากกัน: ความชอบ, ความไว้ใจ, ความเคารพ, ความกลัว, ความเป็นปฏิปักษ์ (0–100)
- Inventory และ Quest พร้อมรายละเอียดและสถานะ
- เรเวน: แชตส่วนตัวกับโมเดลที่เลือกใช้อยู่ใน SillyTavern โดยใช้ `generateQuietPrompt()` และมีคำสั่งจัดการเกมที่จำกัดประเภท
- AI Tracker: หลังคำตอบ AI จะเรียกโมเดลเบื้องหลังเพื่อสกัดการเปลี่ยนแปลงเกมเป็น JSON แล้วตรวจสอบก่อนบันทึก
- Prompt injection: ส่งสถานะเกมล่าสุดให้ AI ในการสร้างคำตอบรอบถัดไปผ่าน `setExtensionPrompt()`
- ย้ายข้อมูลเก่าจาก `rpg_engine_data` มาเป็น `rpg_engine_v2` อัตโนมัติ

## หมายเหตุสำคัญเรื่อง AI Tracker

เมื่อเปิด Auto Tracker (ค่าเริ่มต้น: เปิด) ส่วนเสริมจะเรียก AI เบื้องหลังอีก 1 ครั้งหลังคำตอบของตัวละครแต่ละครั้งเพื่อวิเคราะห์การเปลี่ยนแปลง จึงใช้โควตา/ค่าใช้จ่ายเพิ่มตาม API และโมเดลที่เลือกไว้ หากไม่ต้องการค่าใช้จ่ายเพิ่ม ให้ปิด `ให้ AI ตรวจจับการเปลี่ยนแปลงเกมอัตโนมัติ` ในแผง Extensions

Tracker ใช้คำสั่งให้โมเดลบันทึกเฉพาะเหตุการณ์ที่เกิดขึ้นแล้วและมีหลักฐานในเนื้อเรื่อง พร้อมเกณฑ์ความมั่นใจเริ่มต้น 78% อย่างไรก็ตาม การสกัดด้วย LLM ไม่สามารถรับประกันความถูกต้อง 100% ควรตรวจข้อมูลสำคัญในหน้าต่าง RPG Engine หากต้องการให้รอการยืนยันก่อนบันทึก ให้ปิด `บันทึกการเปลี่ยนแปลงที่ AI ตรวจพบโดยอัตโนมัติ` แล้วกดยืนยันรายการที่ค้างในแท็บภาพรวม

## เรเวนและ Lorebook

- เรเวนใช้โมเดล/API ปัจจุบันของ SillyTavern ผ่าน `generateQuietPrompt()` ไม่ใช่คำตอบสำเร็จรูป
- คำตอบในแท็บเรเวนเป็นบทสนทนาส่วนตัวของ Extension ไม่ถูกส่งลงในประวัติแชตเนื้อเรื่องหลัก
- การเรียก `generateQuietPrompt()` ใช้บริบทแชตปัจจุบัน และ World Info/Lorebook ที่ SillyTavern นำเข้า Prompt ตามการตั้งค่าปกติ
- ในหน้าเรเวนมีปุ่มคัดลอกแนวทาง Lorebook และในแพ็กเกจมี `RAVEN_LOREBOOK_TH.txt` สำหรับสร้างรายการ World Info ชื่อ “เรเวน” เพิ่มเติม
- Prompt injection จะบอกโมเดลหลักว่าผู้ช่วยสามารถถูกเรียกด้วย `@เรเวน` หรือ `@ระบบ` ได้ การให้โมเดลหลักแสดงบทพูดผู้ช่วยในเนื้อเรื่องเป็นการสวมบทบาทโดยโมเดลหลัก ไม่ใช่การส่งข้อความจากตัวละครแยก

## ติดตั้ง/อัปเดต

1. ให้แน่ใจว่าโฟลเดอร์ Extension ใน SillyTavern ชื่อ `RPG-engine` หรือ `RPG-Engine` และมีไฟล์ `manifest.json`, `index.js`, `style.css` อยู่ระดับบนสุดของโฟลเดอร์
2. ติดตั้งผ่าน Extensions → Install extension โดยใช้ URL Repository นี้: `https://github.com/MeDerrito1/RPG-engine`
3. เมื่ออัปเดต ให้แทนที่ไฟล์เดิมใน Repository ด้วยไฟล์เวอร์ชันใหม่ แล้วใช้ Update ใน Manage extensions หรือ reload หน้า SillyTavern
4. เปิด Extensions → RPG Engine (แผงแบบเลื่อนลง) เพื่อเปิด/ปิดปุ่มลอยและ Auto Tracker

## การสำรองข้อมูล

ข้อมูลเกมถูกบันทึกใน metadata ของห้องแชตปัจจุบัน ควรสำรองแชตก่อนทดสอบรุ่นใหม่ โดยเฉพาะเมื่อมีรูปโปรไฟล์จำนวนมาก รูปจะถูกบีบอัดและเก็บเป็น data URL ในข้อมูล NPC/ผู้ช่วยของห้องแชต

## ข้อกำหนดความเข้ากันได้

ต้องใช้ SillyTavern build ที่รองรับ `SillyTavern.getContext()`, `chatMetadata`, `saveMetadata()`, `setExtensionPrompt()` และ `generateQuietPrompt()` หากโฮสต์/ผู้ให้บริการปิด API บางรายการ ฟีเจอร์ที่เกี่ยวข้องจะไม่ทำงาน แม้ UI จะเปิดได้
